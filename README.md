# GoZayaan Flight Results

GoZayaan iOS take-home project for a single flight-results screen built with SwiftUI.

## Status

The repository currently contains the Xcode app scaffold, an XCTest target, a technical specification, and a sample API response. The app displays the template screen; flight search and the planned architecture are not implemented yet.

## Requirements

- Xcode 26 or later, recommended for the generated project and its concurrency settings.
- An iOS 17+ simulator or device to run the app.
- An iOS 26+ simulator or device to run the current test target.

## Run the app

1. Open `iOS-Flight-Results/iOS-Flight-Results.xcodeproj` in Xcode.
2. Select the `iOS-Flight-Results` scheme.
3. Choose an installed iPhone simulator and press **Command-R**.

For a physical device, select your own development team under Signing & Capabilities. The project currently contains the author's signing team.
